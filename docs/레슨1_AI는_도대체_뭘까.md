## 본문 (400~600자)
옛날 AI는 사람이 규칙을 하나하나 정해서 만들었어요. 그런데 "사과를 구별하는 규칙"을 정한다고 해봐요. "빨갛다"라고 하면 초록 사과가 걸리고, "둥글다"라고 하면 납작한 사과가 걸립니다. 규칙을 세울수록 예외가 계속 생겨나죠.

그래서 요즘 AI는 방향을 바꿨습니다. 규칙을 사람이 다 적는 대신, 예시를 잔뜩 보여주고 AI가 스스로 규칙을 찾게 하는 거예요. 사과 사진 5만 장을 보여주면 AI는 색깔, 모양, 질감, 꼭지 모양까지 종합해서 "이게 사과구나"를 스스로 배웁니다.

이렇게 데이터를 보고 스스로 배우는 방식을 '머신러닝'이라 부르고, 여러 층을 쌓아 더 똑똑하게 만든 것이 '딥러닝', 그 위에서 글을 쓰고 그림을 그리는 것이 오늘날의 '생성형 AI'(챗봇, 이미지 생성 도구 등)입니다. 즉 AI는 정해진 대로만 움직이는 로봇이 아니라, 수많은 예시를 보고 스스로 패턴을 찾아낸 결과물이에요.

## 비유·예시 (최소 1개)
아이에게 사과를 가르치는 상황을 떠올려보세요. "빨간 것"이라고 말하면 초록 사과가 예외로 나오고, "둥근 것"이라고 말하면 납작한 사과가 예외로 나옵니다. 말로 규칙을 딱 정해주는 대신 사과 사진을 수천 장 보여주면, 아이(AI)는 스스로 "사과다움"이 무엇인지 알아챕니다. AI가 배우는 방식도 이와 똑같습니다.

## 실습 프롬프트 (1개)
```
초등학생도 이해할 수 있게, AI가 무엇을 보고 스스로 배우는지 사과를 예로 들어서 3문장으로 설명해줘.
```

## 퀴즈 (2~3문항, 객관식)

### 문항 1
Q. 오늘날 우리가 쓰는 챗봇, 이미지 생성 AI는 어떤 방식으로 만들어졌나요?
1. 사람이 모든 규칙을 하나하나 프로그래밍했다
2. 수많은 예시(데이터)를 보고 AI가 스스로 규칙을 찾았다
3. 우연히 만들어졌다
4. 정답이 정해져 있지 않다
- 정답: 2
- 해설: 오늘날의 AI는 사람이 규칙을 다 적는 대신, 데이터를 보고 스스로 패턴을 찾는 '머신러닝' 방식으로 만들어집니다.

### 문항 2
Q. "사과를 구별하는 규칙"을 사람이 직접 정하기 어려운 이유는 무엇인가요?
1. 사과는 원래 정의할 수 없는 과일이라서
2. 규칙을 세울 때마다 예외(반례)가 계속 나오기 때문에
3. AI가 사과를 인식하지 못해서
4. 사과 사진이 부족해서
- 정답: 2
- 해설: "빨갛다", "둥글다" 같은 규칙은 초록 사과나 납작한 사과 같은 예외에 부딪힙니다. 그래서 규칙 대신 예시로 배우는 방식이 등장했습니다.
