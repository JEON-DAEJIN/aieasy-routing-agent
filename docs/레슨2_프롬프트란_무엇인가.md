# 레슨 2. 프롬프트란 무엇인가

## 본문 (400~600자)
프롬프트란 우리가 AI에게 건네는 '요청의 말'입니다. 같은 AI라도 프롬프트를 어떻게 쓰느냐에 따라 답변의 질이 크게 달라져요. 그 이유는 AI가 능력이 없어서가 아니라, 우리가 준 지시가 애매했기 때문인 경우가 많습니다.

예를 들어 "친절하게 배송 정보를 알려줘"라는 지시는 애매합니다. 주문 번호가 없으면 AI는 아무 정보나 지어낼 수도 있어요. 반면 "주문 번호가 없으면 배송일을 단정하지 말고, 주문 번호를 먼저 물어봐줘"처럼 조건을 구체적으로 적으면, AI는 훨씬 정확하게 답합니다.

즉 좋은 프롬프트는 AI에게 '무엇을, 어떤 형식으로, 어떤 조건에서' 답해야 하는지 분명히 알려주는 것입니다. 답변이 마음에 안 들 때는 AI 탓을 하기 전에 내 프롬프트부터 다시 살펴보는 습관을 들여보세요.

## 비유·예시 (최소 1개)
AI를 요리사, 프롬프트를 레시피라고 생각해보세요. 레시피가 "맛있게 만들어주세요"처럼 애매하면 요리사도 무엇을 만들어야 할지 헷갈립니다. 하지만 "토마토 파스타를 매콤하게, 4인분으로 만들어주세요"처럼 구체적으로 적으면 원하는 요리가 나올 확률이 훨씬 높아집니다. 프롬프트도 마찬가지예요 — 구체적일수록 원하는 답에 가까워집니다.

## 실습 프롬프트 (1개)
```
다음 문장을 더 구체적인 프롬프트로 고쳐서 AI에게 입력해보세요.
원래 문장: "보고서 잘 써줘"
힌트: 누가 읽을 보고서인지, 분량은 얼마인지, 어떤 순서로 쓸지를 넣어서 다시 요청해보세요.
```

## 퀴즈 (2~3문항, 객관식)

### 문항 1
Q. 같은 AI에게 물어도 프롬프트에 따라 답변의 질이 달라지는 가장 큰 이유는 무엇인가요?
1. AI마다 실력 차이가 크기 때문에
2. 지시가 구체적인지 애매한지에 따라 AI가 이해하는 내용이 달라지기 때문에
3. AI는 원래 매번 다른 대답을 하도록 설계되었기 때문에
4. 질문이 길수록 무조건 답이 좋아지기 때문에
- 정답: 2
- 해설: 프롬프트가 애매하면 AI도 무엇을 원하는지 정확히 파악하기 어렵습니다. 조건과 형식을 구체적으로 알려줄수록 원하는 답에 가까워집니다.

### 문항 2
Q. 다음 중 더 좋은 프롬프트는 무엇인가요?
1. "배송 정보 알려줘"
2. "주문 번호가 없으면 배송일을 단정하지 말고, 주문 번호를 먼저 물어봐줘"
3. "아무거나 알려줘"
4. "잘 부탁해요"
- 정답: 2
- 해설: 조건과 원하는 행동을 구체적으로 명시한 지시가 AI로부터 더 정확하고 예측 가능한 답을 이끌어냅니다.
