# AI Easy 레슨 챗봇 — 라우팅 에이전트 프로젝트

아이펠 **N039 "나만의 고객응대 에이전트 만들기"** 과제 제출 저장소입니다.

## 왜 이 주제인가

주제는 가상 시나리오가 아니라, 제가 실제로 만들고 있는 서비스 **[AI Easy(에이지)](https://github.com/JEON-DAEJIN/ai-easy)** 의 레슨 챗봇입니다. AI Easy는 AI 초보자를 위한 학습 앱으로, 레슨을 마치면 "더 궁금하면 챗봇에게 물어보세요" 버튼이 뜨고 Cloudflare Workers + Claude API로 만든 챗봇이 응답합니다.

문제는 지금 배포돼 있는 챗봇([`04_개발/챗봇-서버리스/src/index.js`](https://github.com/JEON-DAEJIN/ai-easy/blob/main/04_개발/챗봇-서버리스/src/index.js))이 사용자 질문을 그대로 Claude에 넘기기만 한다는 것입니다.

- 질문이 어떤 종류인지 분류(라우팅)하지 않는다
- 레슨 본문을 실제로 읽고 답하는 게 아니라(그라운딩 없음) `lesson_id` 문자열 하나만 프롬프트에 넣는다
- 답변이 근거에 맞는지 검증하는 절차가 없다
- 성능을 잴 평가셋이 없어 "잘 되는 것 같다"는 느낌으로만 판단하고 있었다

N039 과제가 요구하는 라우팅→근거 조립→답변→검증→측정 구조를 이 실제 챗봇에 적용해보는 것이 이 프로젝트의 목표입니다. 여기서 검증된 설계는 실제로 `ai-easy` 저장소의 Worker 코드에 반영할 계획입니다.

## 카테고리 설계 (3조건 확인)

| 카테고리 | 연결 문서 | 커버하는 레슨/문서 |
|---|---|---|
| 개념이해 (CONCEPT) | `docs/레슨1_AI는_도대체_뭘까.md`, `docs/레슨3_AI가_잘하는것_못하는것.md` | L01, L03 — "AI가 뭔지, 뭘 잘하고 못하는지" |
| 프롬프트작성 (PROMPT) | `docs/레슨2_프롬프트란_무엇인가.md`, `docs/레슨4_나만의_첫_프롬프트_써보기.md` | L02, L04 — "질문을 어떻게 잘 쓰는지" |
| 활용·확장 (APPLY) | `docs/레슨5_AI로_일상문제_해결하기.md`, `docs/레슨6_AI를_계속_배우는법.md` | L05, L06 — "실생활 적용, 다음 단계" |
| 서비스이용 (SERVICE) | `docs/서비스이용_안내.md` | 요금·무료 횟수·진도·향후 트랙 등 앱 자체에 대한 질문 |
| 범위 밖 (OUT_OF_SCOPE) | 없음 → 넘기기 | 트랙1과 무관한 질문(다른 트랙 문의, AI Easy와 무관한 일반 질문) |

- (1) 카테고리 3~5개: 5개 ✅
- (2) 범위 밖 카테고리: OUT_OF_SCOPE ✅
- (3) 카테고리별 실제 근거 문서: 전부 `docs/`에 실존 ✅ (모두 `AIEasy` 프로젝트에서 실제 검수·확정된 콘텐츠)

## 디렉토리 구조

```
aieasy-routing-agent/
├── docs/                        # 근거 문서 (AI Easy 레슨 1~6 원본 + 서비스이용 안내)
├── data/
│   ├── eval_set.csv             # 평가셋 (입력 + 정답 카테고리) — 20건 이상 예정
│   └── answer_gold.json         # 문항별 기대도구·필수사실·금지사실
├── prompts.py                   # 분류 지침 · 답변 규칙
├── context.py                   # 카테고리 → 근거 조립
├── agent.py                     # LangGraph 파이프라인 (판정→근거조립→답변→검증)
├── evaluate.py                  # 도구 호출 적절성 · 답변 적절성 측정
├── app.py                       # 데모 화면 (streamlit)
├── requirements.txt
└── REPORT.md                    # 설계·실험 보고서 (7항목)
```
